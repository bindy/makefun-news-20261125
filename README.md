Entry for the make.fun bounty [Sum up 25 November's world news in one image](https://make.fun/bounty/news-image-20261125).

`build_image.py` draws the image from 30 stories reported on 25 November 2026: the Houthi strike on Riyadh's tallest tower, the claimed Saudi refinery attack, the Gaza strike, Russian strikes on Ukraine's power grid, the NATO meeting, the US tariff plan, the Shanghai graft probe, the first US bird-flu death in a dairy worker, and more. The entry program `main.py` copies the finished image to `/output/entry.png`.

## Run it

```sh
python3 build_image.py   # rebuilds entry.png (1024x1024)
python3 main.py          # writes /output/entry.png
```
